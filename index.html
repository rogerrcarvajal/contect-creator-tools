📁 04-extractor-shorts-virales/

4. Extractor de Shorts Virales (Python + Web Studio)

Automatización completa para extraer 3 Shorts verticales de 40s desde videos largos (`podcast_full.mp4`), combinando script Python (`extractor_shorts.py`) y estudio web.

  • 1. Audio & Whisper: Transcripción automática con marcas de tiempo por palabra (`timestamps`).
  • 2. Análisis LLM: Identifica los 3 fragmentos de 40s con mayor controversia y valor.
  • 3. Reencuadre FFmpeg: Crop central a `1080x1920` (9:16) a 60 FPS.
  • 4 & 5. Subtítulos y Render: Subtítulos gruesos centrados iluminando en amarillo la palabra actual en 3 videos independientes.
Prompt Oficial #3 (Skool):
"Actúa como Productor de Contenido y Desarrollador Python. Tengo un video de un podcast (podcast_full.mp4). Quiero un script de Python que automatice la creación de Shorts. Flujo: 1. Extrae el audio y transcríbelo con Whisper (timestamps). 2. Analiza el texto usando LLM para identificar los 3 fragmentos de 40 seg con mayor controversia/valor. 3. Reencuadre: Aplica un crop central a 1080x1920 usando FFmpeg a esos fragmentos. 4. Subtítulos: Añade subtítulos gruesos al centro, iluminando en amarillo la palabra actual. 5. Renderiza los 3 videos independientes."

💻 Modo Local (Google Antigravity + Python + FFmpeg)

Indispensable cuando las herramientas requieren procesamiento pesado de archivos locales y modelos de IA:

  • Acceso directo al sistema de archivos para procesar brutos largos (`podcast_full.mp4`) sin límites de RAM del navegador.
  • Ejecución de OpenAI Whisper local para transcripción precisa con timestamps por palabra.
  • Pipeline FFmpeg (`libx264`) para recorte `1080x1920`, detección de silencios (`silencedetect`) y quemado `.ASS`.
