Extractor Automático de Shorts Virales (Whisper + LLM + FFmpeg)

Detección de 3 Fragmentos de 40s + Crop Central 1080x1920 + Subtítulos Amarillos Activos • Por Rogerr Carvajal

🏠 Volver al Hub 🐍 Descargar Script .PY

🚀 Pipeline Automatizado de 5 Etapas (podcast_full.mp4 → 3 Shorts 9:16)

1. Audio & Whisper Timestamps por palabra extraídos
2. Análisis LLM Top 3 fragmentos de 40s (Controversia/Valor)
3. Crop FFmpeg Reencuadre central 1080x1920 (9:16)
4. Subtítulos Pro Palabra actual iluminada en amarillo
5. Multi-Render 3 videos MP4 independientes
🐍 Comando CLI Python + FFmpeg Generado (`extractor_shorts.py`): 
python extractor_shorts.py --input podcast_full.mp4 --output-dir output_shorts --render

# Flujo interno FFmpeg por cada uno de los 3 fragmentos de 40s:
ffmpeg -y -ss 120.0 -t 40.0 -i podcast_full.mp4 \
  -vf "crop=ih*9/16:ih,scale=1080:1920,fps=60,ass='output_shorts/short_01_subtitles.ass'" \
  -c:v libx264 -preset fast -crf 18 -c:a aac -b:a 192k output_shorts/short_01_viral_1080x1920.mp4
